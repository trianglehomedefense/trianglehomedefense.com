# Simple Lead Pipeline

Recommended immediate platform: Google Sheets. Airtable can come later if needed. Use Notion only if the family already uses it consistently.

Columns:

- Date Created
- Lead / Property Name
- Contact Name
- Phone
- Email
- Property Address
- County
- Track
- Lead Source
- Problem / Concern
- Inspection Scheduled
- Inspection Date
- Photos Folder Link
- Report / Estimate Link
- Estimate Status
- Decision Status
- Owner Assignment
- Next Action
- Follow-Up Date
- Priority
- Revenue Potential
- Risk / Liability Flag
- Referral Needed
- Notes

Track options: THD Lead, Personal / Family Property, Murphy / Mossy Pass, Future Idea Backlog.

Priority options: Low, Medium, High, Critical.

Private operations context: do not publish family logistics on the public website. Murphy / Mossy Pass is a personal/family stewardship track, not public THD business. AT&T/phones, vehicle status, and childcare handoffs should be tracked as operating dependencies where relevant.
